# 분석 방법 상세

README의 핵심 결과를 만든 분석 단계별 방법입니다. 검증 종합표는 [README](../README.md#모형-검증-종합)에 있습니다.

### STEP 1. 선수 해부 리포트
투수와 타자 전원에게 같은 템플릿을 자동으로 적용합니다.

| 투수 | 타자 |
|---|---|
| ERA, FIP, WHIP, K%, BB%, xwOBA 성적 카드 | 타율, OPS, wOBA, xwOBA 성적 카드 |
| Baseball Savant 스타일 리그 백분위 | 타구속도, 배럴%, 배트 스피드 백분위 |
| 구종 수, 좌우 타자별 구사율, 시즌별 구종 변화 | 구종별 상대 타율, xwOBA, 헛스윙률 |
| 구종별 구속, 회전, 무브먼트, 익스텐션, 일관성 | Statcast 9분할 존별 성적 |
| 좌우 타자로 나눈 구종별 투구 위치 히트맵 | 위치별 헛스윙률과 타구 xwOBA 히트맵 |
| 구종별 피안타율, xwOBA, Whiff%, 하드힛%, 구종가치 | 패스트볼 구속대별, 볼카운트별 성적 |
| 볼카운트별 구사율, 마르코프 방식의 구종 전이 확률 | 좌우 투수 스플릿, 스프레이 차트 |

### STEP 2. 유형 분류
투수는 규칙 기반으로 나눴습니다. 패스트볼과 주력 보조구종의 조합에 따라 9개 유형이 나옵니다.
- 유형: 포심-슬라이더, 포심-스위퍼, 포심-커브, 포심-체인지업, 포심-스플리터, 싱커-슬라이더, 싱커-커브, 싱커-체인지업, 커터형
- 태그: 97mph 이상이면 강속구, 수직무브 17in 이상이면 하이 포심, GB 50% 이상이면 땅볼형을 붙입니다. 구종 수로는 2피치, 3피치, 다양형을, 보직으로는 선발과 불펜을 구분합니다.
- Ward 방식의 계층적 군집 덴드로그램으로 9개 유형을 성향에 따라 다시 묶어 상위 그룹을 만들었습니다.
- 선형판별분석(LDA)으로는 구종 비율 없이 공의 물리 특성만으로 유형을 맞혀 봤습니다. 유형이 실제로 존재하는지 확인하려는 것이고, 투수 단위 교차검증과 혼동행렬로 평가했습니다.
- Kruskal-Wallis 검정과 FDR 보정을 적용한 Dunn 사후검정으로 유형별 삼진, 땅볼, 헛스윙 등의 성적 차이를 검정하고 효과크기 ε²를 구했습니다.
- 대응분석(CA)으로 유형과 타석 결과의 관계를 지도로 그렸습니다. 타석 결과는 삼진, 볼넷, 땅볼, 뜬공, 안타, 장타, 홈런으로 나눴습니다.
- 유형 전환 분석에서는 시즌 사이의 유형 흐름을 Sankey 다이어그램으로 보고, 직전 성적과 나이를 통제한 이중차분형 비교를 했습니다.
- K-means 자동 군집은 규칙 유형과 얼마나 일치하는지 ARI로 비교하는 데만 썼습니다.

타자는 데이터 기반으로 군집했습니다. VIF → 표준화 → K-means → PCA 순서로 진행했고, K-means 단계에서는 엘보우, 실루엣, Davies-Bouldin, GMM BIC를 함께 봤습니다. 안정성은 부트스트랩 ARI로 확인합니다.

### STEP 2-1. 프로필 레이더
- 선수와 같은 유형의 평균을 리그 백분위로 겹쳐 그려 강점과 약점을 비교합니다. 바깥쪽이 좋은 쪽이 되도록 방향을 통일했습니다.

### STEP 3. 요인 분석: LightGBM과 SHAP
- 구위 지수: 구종의 물리 특성만으로 헛스윙률을 예측하고, 같은 구종 그룹 평균을 100으로 놓고 지수화했습니다. 그 투수를 뺀 모델의 교차검증 예측값을 쓰기 때문에 지수에 자기 실제 헛스윙률이 섞이지 않습니다.
- 타자 생산성 모델: 스윙, 선구, 타구 과정 지표로 wOBA를 예측합니다. wOBA의 성분인 K%와 BB%는 입력에서 뺐습니다.
- 선수 단위 GroupKFold로 교차검증하고, TreeSHAP으로 변수별 기여도와 의존도를 분석했습니다.
- 올해 구위 지수가 내년 헛스윙률을 얼마나 예측하는지도 확인했습니다. 실제 헛스윙률보다는 예측력이 낮아서, 표본이 적을 때 쓰는 사전 추정용으로 보는 게 맞습니다.

### STEP 3-1. 종합 지수: 엔트로피 가중법, SHAP 가중치, Min-Max
- 지표 방향을 통일하고, 시즌별로 Min-Max 정규화한 뒤 가중합해 0~100점으로 만듭니다.
- 엔트로피 가중법은 선수 간 정보량을, SHAP 가중치는 성적 영향력을 기준으로 삼습니다. 두 방식으로 지수를 따로 만든 뒤 다음 시즌 성적 예측력이 더 높은 쪽을 최종 지수로 골랐습니다.
- 비교 기준은 xwOBA 하나만 썼을 때의 예측력입니다.

### STEP 3-2. 볼배합 네트워크 분석
- 구종을 노드로, 연속 투구를 방향 간선으로 놓고 투수별 그래프를 만들었습니다.
- PageRank로 허브 구종을 찾고, 조건부 엔트로피로 볼배합이 얼마나 예측하기 어려운지 쟀습니다. 간선별 헛스윙률로는 위력적인 연결을 골라냅니다.
- 리그 전체로는 볼배합 엔트로피가 삼진과 피xwOBA에 미치는 영향을 봤습니다. 구위와 구종 수를 통제한 회귀입니다.

### STEP 4. 기대 성적: Huber 회귀, HAC, FDR
- 결과와 과정의 차이는 타석별 wOBA에서 xwOBA를 뺀 값의 평균으로 잽니다. wOBA는 실제 결과이고, xwOBA는 타구 질로 본 기대값입니다.
- 경기 순서에 따른 자기상관은 Ljung-Box로 진단하고 Newey-West(HAC) 표준오차로 보정했습니다.
- 수백 명을 동시에 검정하므로 Benjamini-Hochberg FDR 보정을 적용합니다.
- 기대 ERA는 Huber 로버스트 회귀로 추정했습니다. 식은 ERA ~ K% + BB% + GB% + HardHit%입니다.
- OLS와 Theil-Sen으로도 추정해 잔차 순위와 불운 상위 20명의 겹침을 비교했습니다. 회귀 방법을 무엇으로 고르느냐에 결과가 좌우되지 않는지 보려는 것입니다.
- 선형성은 잔차와 예측값의 LOWESS 곡선으로, 이상치를 포함한 잔차 분포는 Q-Q 플롯과 왜도, 첨도로 진단했습니다.
- 갭과 실력 지표인 K%의 연도 간 지속성도 비교했습니다. 갭이 다음 해로 이어지지 않는 일시적 요인인지 확인하기 위해서입니다.

### STEP 5. 공간 분석: Moran's I, LISA
- 스트라이크존을 10×10 격자로 나누고, 칸 사이의 rook 인접 관계로 공간 가중치를 구성했습니다.
- Global Moran's I 순열검정으로 타자의 약점이 특정 구역에 뭉쳐 있는지 봅니다.
- LISA로는 칸마다 핫스팟(HH)과 콜드스팟(LL)을 판정합니다.

### STEP 6. 맞대결 예측: Log5, LightGBM, 행렬 분해
- 희소성 문제는 실제 맞대결 기록 대신, 투수와 타자 각자의 수천 구 데이터로 만든 특성으로 예측해서 풀었습니다.
- 누수를 막기 위해 시즌 s의 타석은 시즌 s−1의 특성으로 예측하고, 2026시즌 전체는 검증용으로 완전히 떼어 놨습니다.
- 타석 결과는 삼진, 볼넷과 사구, 1루타, 2루타와 3루타, 홈런, 범타의 6가지로 분류합니다.
- 모델은 리그 평균 → Log5 공식 → 유형 대 유형 교차표 → 다항 로지스틱 회귀 → LightGBM 순서로 비교했고, 마지막으로 행렬 분해(ALS)로 궁합 잔차를 보정했습니다.
- 구종 조합 기대값은 Σ (투수의 구종별 구사율 × 타자의 구종별 xwOBA)로 구하고, 경험적 베이즈 축소를 적용했습니다.
- 평가는 로그 손실, Brier 점수, 보정 곡선으로 했고, 자주 만난 쌍에서는 예측과 실제를 직접 비교했습니다.

### STEP 7. ABS 전후 비교: 단절 시계열, 이중차분형 비교
- 단절 시계열(ITS)은 월별 지표 ~ ABS 더미 + 연도 추세 + 월 고정효과로 놓고 HAC 표준오차를 썼습니다.
- 판정 지도는 격자 칸마다 콜 스트라이크율 변화를 두 비율 z검정으로 보고 FDR로 보정했습니다.
- 누가 손해를 봤는지는 직전 시즌에 경계 콜 의존도가 높던 투수일수록 볼넷이 늘었는지를 회귀로 확인했습니다.
- 위약(placebo) 검정으로 같은 분석을 도입 전 구간인 2024→2025에 적용해, 원래 있던 추세가 아닌지도 확인했습니다.

### STEP 8. 시간에 따른 변화: 혼합효과모형, 변화점 탐지
- 에이징 커브는 선수별 무작위 절편을 둔 혼합효과모형으로 그리고, 델타 방법과 비교해 생존 편향을 점검했습니다.
- 구속 급락 경보는 경기별 패스트볼 구속에서 평균이 바뀌는 변화점을 찾아, −1.5mph 이상 떨어지고 t ≤ −4이면 울립니다. 가장 큰 변화 지점을 고르는 방식이라 기준을 엄격하게 잡았습니다.
